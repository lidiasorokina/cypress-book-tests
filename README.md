# Cypress Tests for Book Application

Автотесты для приложения "Создание и хранение книг"

## Установка

```bash
npm install

Запуск приложения
# Терминал 1 - клиент
npm start

# Терминал 2 - сервер
npm run server

Запуск тестов
npx cypress open

Тесты
Авторизация
Добавление книги в избранное
Удаление книги из избранного
